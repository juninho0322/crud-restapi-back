API meaning

What exactly is the API?

The API is the agreed doorway between frontend and backend. Your frontend does not talk to controllers or databases directly. It sends HTTP requests to API endpoints, and the backend returns JSON.

API endpoint example:

POST /api/tasks

Frontend sends:
{ "title": "Study API" }

Backend returns:
{ "data": { "id": "...", "title": "Study API" } }
